“Total” runs from the keystroke to the other device holding the text, so it includes the push debounce. “Minus debounce” is what the server, network and hint add. Go offline on one device, edit both, then bring it back to see the conflict rule: the first writer to reach the server wins and the other text is kept as a conflict copy.
