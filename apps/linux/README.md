# Linux native app

A native Linux desktop app for Composition: Rust, GTK 4 and libadwaita. **Design and spikes only. There is no production code here, and
there will be none until the Linux native app's Gate A is passed.** The Electron app, including its Linux build, stays the shipping plan.

- The design: [docs/linux-native-app-design.md](../../docs/linux-native-app-design.md)
- The spikes and what a container can and cannot show: [spikes/README.md](spikes/README.md)

Nothing in this folder is part of the root workspace or built by CI.
